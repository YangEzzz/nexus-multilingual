# Nexus UI 重构验证

本轮按用户要求采用与 Helios 一致的黑白灰主体和鲜明蓝、绿、橙、紫内容点缀；两个系统均移除全局顶部栏，导航、外观和账号集中在侧栏。

Nexus 更新范围：应用壳、可调整侧栏、项目列表、项目总览、工作台、语言库、日志、AI 设置、登录页及共享弹窗/表格样式。Helios 同步更新主体布局、统计与入口图标、项目卡片和状态标签点缀。

- Nexus `pnpm check`：零警告 lint、类型检查、9 项回归和 16 项 API 契约通过。
- 两个前端生产构建与 premium strict 静态审计通过。
- 浏览器验证采用真实组件与内存 API：搜索/清除焦点、无结果、空项目、加载失败、项目表单、词条抽屉、保存失败保留输入、保存成功、筛选弹出层与 Escape、侧栏 220/360px 边界、深色模式和手机抽屉。
- Nexus 筛选下拉与触发器均为 138px。375px 工作台无页面水平溢出，宽表格由自己的容器水平滚动。
- 测试不修改真实项目、登录凭据或后端配置；截图中的项目和统计为测试数据。

预览见 `docs/screenshots/ui-refactor/`；Helios 预览为 `docs/ui-preview/workspace-accents.png`。
